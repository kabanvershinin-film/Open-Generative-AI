# debug-photo-disappears-on-select

Status: [OPEN]

## Symptom
Фото пропадает сразу после выбора.

## Hypotheses
1. Превью строится из временного object URL, и он сразу ревокается или теряется при ререндере.
2. Компонент при выборе файла сбрасывает state и заменяет выбранный файл на пустое значение.
3. Валидация/нормализация файла отклоняет изображение из-за MIME-типа, размера или имени.
4. Обработчик `onChange` получает файл, но затем другой эффект/синхронизация перезаписывает его старым значением.
5. Upload pipeline возвращает ошибку, и UI очищает выбранный файл после неуспешной попытки.

## Notes
- Instrumentation only first; no business logic fixes yet.
