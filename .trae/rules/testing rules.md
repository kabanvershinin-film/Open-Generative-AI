## Тестирование

### Фреймворк
- Использовать только node:test + node:assert (встроенные в Node.js)
- НЕ устанавливать Jest, Mocha или другие внешние фреймворки
- Запуск: node --test (скрипт в package.json: "test": "node --test")

### Расположение тестов
- Файлы тестов: __tests__/название.test.js рядом с модулем
- Или: moduleName.test.js рядом с исходником

### Приоритетные модули
- studio/muapi.js — API-запросы, поллинг, авторизация (401/402)
- studio/models.js — фильтрация моделей T2V, I2V, V2V
- api/route.js — роуты Volcano Engine / Ark Seedance
- packages/workflow-builder/utility.jsx — утилиты узлов

### Обязательные правила
- При изменении функции — проверить наличие теста, при отсутствии создать
- При добавлении новой функции — добавить тест обязательно
- Тесты должны проходить без ошибок (node --test) перед каждым коммитом
- Мокировать внешние API-вызовы (fetch, axios) через mock в node:test
