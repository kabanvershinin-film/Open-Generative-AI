# debug-image-generation-editing

Status: [OPEN]

## Symptoms
Нужно восстановить работоспособность генерации изображений и редактирования изображений.

## Hypotheses
1. Бизнес-логика вызывает устаревшие или удалённые debug-вызовы / переменные, из-за чего падает render и ломаются оба сценария.
2. `ImageStudio` передаёт в API неверную форму данных для генерации или редактирования, и запросы умирают до отправки.
3. Сломана связка между UI и `muapi.js`/API-роутами: неправильные параметры, endpoint или формат файла.
4. Редактирование изображения ломается из-за некорректной синхронизации `uploadedImageUrls`, `selectedEntries` или `imageMode`.
5. В прод-сборке остался старый бандл, который отличается от текущего исходника и вызывает runtime errors.
